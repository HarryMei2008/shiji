# 拾季 SHIJI

当季食材订阅品牌官网 · 交互式单页站点 · 中英双语

**简体中文** · [English](README.en.md)

## 线上地址

- 中文版：https://harrymei2008.github.io/shiji/
- 英文版：https://harrymei2008.github.io/shiji/?lang=en
- 或点击导航栏「拾季」旁的 **EN / 中** 按钮随时切换，选择会被记住

## 这是什么

一个虚构的「按季订阅食材」品牌演示站：每季 12 种当季食材，
从云南元谋的番茄到新疆吐鲁番的葡萄，48 小时从产地到餐桌。
本站为课程作品，品牌与数据均为演示用途，不产生真实交易。

## 使用指南

1. **封面** — 向下滚动，或点「配一配今晚的菜」直达核心玩法
2. **当季十二味（3D）** — 拖拽旋转星球，点击食材查看名称与产地
3. **配齐计算器（核心）** —
   ① 勾选你想做的菜（共 6 道）→ ② 勾选家里已有的食材 →
   ③ 圆环实时显示「还差几样」和总价 → ④ 缺的自动汇成清单 →
   ⑤ 点「加入本周箱」生成订阅箱
4. **六道菜** — 每道菜附完整步骤，点开手风琴即可查看
5. **订阅区** — 选周期（每周/双周/每月），价格数字滚动换算
6. **账号与下单** — 注册/登录/下单均为**本地演示**：数据只保存在
   你自己的浏览器（localStorage），不经过任何服务器

## 技术说明

纯静态站点，无框架、无构建步骤、无外部 CDN 依赖。

- HTML / CSS / 原生 JavaScript
- Three.js r149（已本地化至 `vendor/`）
- 首屏视频：H.264 / 720p / 763KB / 5 秒循环 / 无音轨
- 双语方案：自研零依赖 i18n（静态文案 `data-en` 属性 +
  JS 动态文案词典 `js/i18n.js`，缺词自动回退中文）

## 目录结构

```
index.html           单页入口（8 个区块）
css/site.css         设计系统与全部组件样式
js/site.js           滚动动效、配齐计算器、菜单、账号系统
js/i18n.js           中英双语引擎（词典 + data-en）
js/orbit.js          3D「当季十二味」（拖拽阻尼 + Raycaster 拾取）
vendor/three.min.js  Three.js r149
assets/hero-loop.mp4 首屏氛围视频
refs/                视觉参考图与设计变量
```

## 本地预览

```bash
python -m http.server 8000
```

然后打开 http://127.0.0.1:8000

不要直接双击 `index.html` —— `file://` 协议下浏览器会限制
localStorage，账号功能无法保存。
